# Bodo San Calendar (बड़ो सान) • Android App & Website

An authentic Bodo & English Traditional Solar Calendar platform with live cultural research, Bagurumba visual theme, Aronai color system, Supabase broadcast, and 12:00 AM midnight dynamic date rollover.

---

## 🌟 Features Included

1. **Exact Bodo Solar Calendar Engine (Assamese / Bhaskarabda Transition)**:
   - Solar month of **Aasin / Ahin (आसिन / आहिन)** starting on **September 19** (Sep 19 = 1, Sep 20 = 2, Sep 21 = 3).
   - Prominent Bodo Date (Large/Batha) and English Reference Date (Small/Chota).
   - Weekdays: **Rabibar, Sombar, Mongolbar, Budhbar, Brihospatibar, Sakrubar, Shanibar**.
   - 12 Bodo Solar Months: Bwisag, Jeth, Aasar, Sawan, Bhadra, Aasin, Kati, Aghon, Push, Magh, Fagun, Chaitra.

2. **Bagurumba & Aronai Visual Identity**:
   - Hero banner with traditional Bagurumba dancers wearing Dokhona and Aronai scarves.
   - Distinctive Aronai color palette (Gold `#F59E0B`, Red `#DC2626`, Navy `#0F172A`, Green `#16A34A`).

3. **Live System & Research Sync (Supabase)**:
   - Live cultural news ticker with daily research articles on ancient kings, historical movements, and Bathou pujas.
   - User message dismissal / delete button (✕) for all cards.
   - Admin broadcast modal to publish live announcements.

4. **Dual Platform Support**:
   - **Android App**: Native Kotlin Jetpack Compose app with Material 3.
   - **Website / GitHub Pages**: Full standalone responsive web app in `docs/index.html` and `web/index.html`.

## 🚀 How to Host on GitHub & Enable Website

### Step 1: Push from Google AI Studio to GitHub
1. In Google AI Studio, click the **Settings / Export** menu in the top right.
2. Select **Push to GitHub** (or **Export to GitHub**).
3. Connect your GitHub account and choose repository name (e.g. `bodo-calendar`). AI Studio will automatically upload the entire code!

### Step 2: Enable Free Website (GitHub Pages)
1. Open your repository on GitHub.
2. Go to **Settings** → **Pages** (on the left menu).
3. Under **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: Select `main` (or `master`) and folder **/docs**.
4. Click **Save**.
5. Within 1 minute, GitHub will give you a live website link:
   `https://<your-username>.github.io/<repo-name>/`
